# FUTURE_ML_01 — Sales & Demand Forecasting

## Project Overview

This project focuses on analyzing historical sales data and forecasting future monthly sales using Machine Learning techniques.

The goal is to identify sales trends, understand business performance, and help businesses make better inventory and sales planning decisions.

## Objectives

* Clean and preprocess historical sales data.
* Analyze monthly sales trends.
* Build a sales forecasting model.
* Predict sales for the next three months.
* Evaluate model performance using error metrics.
* Visualize historical sales and future predictions.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn
* Google Colab

## Methodology

1. Load and inspect the sales dataset.
2. Handle missing values and duplicate records.
3. Convert order dates into date format.
4. Aggregate sales data by month.
5. Train a Linear Regression model using a time-based feature.
6. Evaluate the model using Mean Absolute Error (MAE) and Root Mean Squared Error (RMSE).
7. Forecast sales for the next three months.
8. Visualize historical sales and forecast results.

## Project Files

* `Sales_Demand_Forecasting (1).ipynb` — Python notebook containing the analysis and forecasting code.
* `Sales_Demand_Forecasting_Outputs.zip` — ZIP file containing the cleaned dataset, monthly sales data, forecast results, model evaluation, and forecast visualization.

## Model Evaluation

The model is evaluated using:

* Mean Absolute Error (MAE)
* Root Mean Squared Error (RMSE)

The actual evaluation values are available in `model_evaluation.csv` inside the output ZIP file.

## Business Benefits

* Supports sales planning.
* Helps estimate future demand.
* Assists inventory management decisions.
* Provides a visual understanding of sales trends.

## Conclusion

This project demonstrates a basic machine learning approach to sales forecasting using historical monthly sales data. The forecast can support business planning, but predictions should be reviewed alongside actual sales patterns and seasonal factors.
